# Django To-Do Application

## Overview

This project is a demonstration of a web-based To-Do application built using the **Django** web framework. It illustrates Django's Model-View-Template (MVT) architecture and demonstrates how to build a complete CRUD application using Django's ORM and built-in development tools.

The application allows users to create, manage, update, and delete tasks while storing data in a SQLite database.

## Technologies Used

* Python 3
* Django
* SQLite
* HTML5
* CSS3
* JavaScript

## Features

* Add new tasks
* View all tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* SQLite database integration
* Django ORM
* Django Admin
* Responsive user interface

## Running the Project

Activate the virtual environment and start the Django development server:

```bash
python manage.py runserver
```

Open your browser:

* Application: http://127.0.0.1:8000
* Django Admin: http://127.0.0.1:8000/admin

## Repository Notice

The complete project directory is **too large to upload directly to GitHub**, primarily because it includes the virtual environment and supporting project files.
